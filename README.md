# 🌿 Green Gaze

Green Gaze is an AI-powered multilingual plant disease detection application built using Flutter and TensorFlow Lite.

## 🚀 Features

* Plant disease detection from leaf images
* AI-powered disease classification
* Confidence score prediction
* Multilingual support

  * English
  * Tamil
  * Hindi
  * Malayalam
* Voice-assisted output
* Camera and Gallery image upload
* Offline TensorFlow Lite inference

## 🛠️ Tech Stack

* Flutter
* Dart
* TensorFlow Lite
* Image Picker
* Flutter TTS

## ⚙️ How It Works

1. User uploads a crop leaf image.
2. The image is preprocessed and sent to the TensorFlow Lite model.
3. The model predicts the disease class.
4. Disease information is retrieved from the local database.
5. Treatment and prevention recommendations are displayed.
6. Voice assistant reads the result in the selected language.
